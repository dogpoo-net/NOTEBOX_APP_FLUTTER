# 작업 인계

## 목표

모바일에서 시작하고 집의 Codex에서도 이어 개발할 수 있는 제텔카스텐 노트박스 앱.

## 현재 범위

- Flutter 기본 프로젝트를 개발 시작점으로 사용합니다.
- 노트 저장·편집·검색·링크 기능은 아직 구현하지 않았습니다.
- 원격 백엔드와 비밀키는 아직 필요하지 않습니다.

## 다음 작업 제안

1. 노트 모델 정의: 고유 ID, 제목, 본문, 생성·수정 시각, 태그, 연결 노트 ID.
2. 노트 목록과 편집 화면 구현.
3. 기기 내 영속 저장과 재시작 후 복원 테스트.
4. 노트 간 링크와 역링크, 검색 추가.

클라우드 작업마다 기존 체크아웃을 사용하세요. 별도 Git worktree는 사용자가 요청한 경우에만 만드세요. 변경 전 git status를 확인하고 기존 작업을 보존하세요.

## 최초 검증 결과

- Flutter 3.47.9 / Dart 3.13.7.
- `bash scripts/setup-cloud.sh`: 성공, 잠금 파일을 유지한 의존성 설치 확인.
- `flutter analyze --no-pub`: 문제 없음.
- `flutter test --no-pub`: 기본 카운터 위젯 테스트 1개 통과.
- `flutter build web --no-pub`: 성공.
- Android/iOS 네이티브 빌드와 실기기 실행은 미검증.

클라우드에서는 `export PATH="/workspace/toolchains/flutter/bin:$PATH"`로 도구를 활성화합니다. 최초 설치/분석/테스트 시 다운로드, 사용자 캐시 쓰기, 테스트 러너의 로컬 소켓 때문에 실행 환경의 승인 절차가 필요할 수 있습니다. 환경 설정 초안 저장은 게시와 별개이므로, 재사용 스냅샷은 환경 설정에서 검토·저장 후 게시하세요.
