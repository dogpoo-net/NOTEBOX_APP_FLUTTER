# NOTEBOX 작업 인계

## 설계 방향
첨부 설계 요약을 바탕으로 빠른 기록함을 첫 화면으로 선택했습니다. 따뜻한 아이보리 배경, 잉크색 본문, 절제된 녹색 강조를 사용합니다. 제목 입력 없이 본문의 첫 줄을 목록 제목으로 표시합니다. 모바일은 작성란 우선, 넓은 화면은 목록과 작성란을 함께 배치합니다.

## 구현
- 빠른 메모 추가, 열기, 수정, 본문 검색.
- 공백 메모 방지, Markdown 원문 보존, 저장 피드백.
- 작성 중 다른 메모를 열 때 변경 손실 확인.
- 로그인과 서버 통신 없음.
- 현재 메모리 기반 UI 프로토타입입니다. 앱 재시작 시 메모는 초기화됩니다. 화면에도 이를 표시합니다.

## 다음 단계
Repository 레이어와 로컬 영속 저장을 검증·추가한 뒤 재시작 복원, 저장 실패, 초안 복원을 테스트합니다. SQLite/Drift는 후보이며 아직 확정하지 않았습니다. 이후 Markdown 미리보기, 태그, 노트 링크와 역링크를 추가합니다. 배포용 앱 식별자는 미확정입니다.

## 개발
Flutter 3.47.9 / Dart 3.13.7. 클라우드에서 `bash scripts/setup-cloud.sh` 후 `export PATH="/workspace/toolchains/flutter/bin:$PATH"`로 활성화합니다.

검증: `flutter analyze --no-pub`, `flutter test --no-pub`, `flutter build web --no-pub`.
기존 체크아웃을 사용하고 사용자가 요청하지 않은 worktree는 만들지 않습니다. Android/iOS 실기기 빌드는 아직 검증하지 않았습니다.

## Material 3 테마 업데이트
Flutter 공식 Material 패키지를 사용합니다. 인디고 기반 의미 색상과 표면 단계, 24px 카드 곡률 및 테두리로 영역을 구분합니다. 상단 테마 메뉴에서 시스템 설정/라이트/다크를 선택하며 초기값은 시스템 설정입니다. 선택은 현재 세션에만 유지됩니다. 메모 및 초안은 테마 전환 시 보존됩니다. 테마 설정 영속화는 로컬 저장 단계에 포함합니다.
